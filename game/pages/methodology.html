Unseen Above

The tools behind the game

The game itself

  • Phaser 4.2.1: the free, open-source game engine.
  • JavaScript, HTML5 Canvas and CSS: all the code, drawing and page layout. There are no image files; every sprite and room is drawn by code.
  • Web Audio API: the browser’s built-in sound system. It generates all the music and sound effects live.
  • localStorage: saves progress, settings and endings in the player’s browser.
  • The CH07 Caption pixel font: hand-made, built into a real font file with Python and fontTools.

Building it

  • Node.js and npm: run the build and manage packages.
  • esbuild: bundles the code into a single page.
  • marked 18.1.2: turns the paper’s Markdown into the paper page.
  • Python: font building, the old itch.io packager, and conversion scripts (like turning your inline citations into footnotes).

Testing and checking

  • Playwright with headless Chromium: plays the game automatically. It runs the 25 test scripts, takes screenshots, and simulates players (the boss bot, the critics).
  • Chrome DevTools Protocol profiler: found the frame-rate spikes in the east wing and episode 4.
  • Pillow (Python imaging): contact sheets of screenshots.
  • The solver: written in-house. It proves every globe puzzle can be finished with no dead ends.

Video

  • MediaRecorder and canvas capture: recorded the trailer with its live game audio.
  • ffmpeg and ffprobe: video encoding, checks and frame grabs.

Code, hosting and files

  • Git and GitHub: the code is in the public repo mikeendrias-coder/unseen-above, on the dev branch.
  • GitHub Pages: hosts the game, paper and trailer at mikeendrias-coder.github.io/unseen-above.
  • gh (GitHub CLI): pushing and setting up Pages.
  • Syncthing: the ~/Sync folder holding the offline copy.
